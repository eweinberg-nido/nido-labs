A collection of small challenges using a Metro RP2040, a breadboard, and the parts already in the makerspace. Start with the wiring. Run code that works. Then change something and see whether you can get it working again.

Before starting: use a USB data cable. If the Metro does not appear as a CIRCUITPY drive, install CircuitPython from the board link. Save the code below as code.py. The online editor works best in Chrome/Chromium; a regular text editor can also edit the CIRCUITPY drive.

Component reference

These are reference photographs of the actual modules. Read the labels printed on your own board before wiring; different versions can arrange the pins differently. The LED picture below is a reference sheet, not a verified pin diagram.

Use 3.3 V for introductory sensors unless a particular part requires something else. Common GND matters. Never feed a 5 V signal into a Metro RP2040 GPIO/ADC pin. Disconnect USB before moving wires. Completion is stored only in this browser. Board documentation.
